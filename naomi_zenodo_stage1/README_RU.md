# NAOMi: картинки zebrafish по образцу Zenodo 6293696

Этот вариант выполняет техническую часть пункта 1 проекта: генерирует
локальные картинки 64×64 и соответствующие маски отдельных синтетических
клеток. Параметры подобраны по реально прочитанным кадрам highSNR.
GAN, обучение сегментации, дистилляция и реалистичная временная активность
в этот этап не входят.

## Самый простой запуск на этом компьютере

1. Открой папку `C:\Users\User\Documents\ChatGPT\Кемп Рыбы\naomi_zenodo_stage1`.
2. Дважды нажми `START_STAGE1.cmd`.
3. Дождись строки `DONE ...`. При успешной проверке в выводе будет
   `"similarity_checks_passed": true`.
4. Папка нового результата появится внутри `generated`, с именем `batch_...`.
5. Сначала открой `comparison.png`, затем `masks_preview.png`.

Octave и Python уже установлены, пакеты уже подготовлены. MATLAB не нужен.
Повторный запуск использует готовые объёмы с seed 21, 22, 23 и воспроизводит
те же примеры в новой папке. Новые геометрии получаются с другими seed.

Из PowerShell можно сделать то же самое:

```powershell
cd 'C:\Users\User\Documents\ChatGPT\Кемп Рыбы'
.\naomi_zenodo_stage1\START_STAGE1.cmd
```

Для 24 картинок из трёх новых сцен:

```powershell
.\naomi_zenodo_stage1\START_STAGE1.cmd --seeds 31 32 33 --images-per-seed 8
```

В проверенных запусках построение новой сцены занимало примерно две минуты
на этом компьютере. Расчёт картинок из уже сохранённых сцен значительно
быстрее. Это наблюдение для данной машины, не обещание времени на другом ПК.

## Что уже сгенерировано

Готовый пример: `generated\zenodo_stage1_final`.

- `images`: 24 отдельных grayscale uint16 TIFF — входы для модели.
- `instance_masks`: 24 uint16 TIFF. Ноль — фон, ненулевой номер — ID клетки.
  Номера сохраняют связь с клеткой в исходной 3D-сцене и могут иметь пропуски.
- `semantic_masks`: бинарные uint8 TIFF, 0/255 — фон/клетки.
- `overlap_masks`: NPZ с отдельными бинарными масками и соответствующими ID.
  Они сохраняют перекрытия, которые один 2D TIFF хранить не может.
- `clean`: float32 картинки до добавления шума; вспомогательная информация.
- `diagnostics`: средние 16 независимых шумовых реализаций той же сцены.
  Эти средние нужны для измерения морфологии. Это не обучающее видео.
- `comparison.png`: реальные и синтетические кадры при общем диапазоне
  отображения; рядом диагностические средние.
- `masks_preview.png`: изображения и границы синтетических масок.
- `manifest.json`: все параметры, seed, происхождение примеров и хеши кода.
- `verification.json`: численное сравнение с реальными вырезками.
- `independent_export_validation.json`: независимое чтение через Pillow и SHA-256.

Для обучения сегментации используй пары с одинаковым именем из `images` и
нужной папки масок. Файлы `clean`, `diagnostics`, `comparison.png` не являются
дополнительными независимыми обучающими примерами.

пресет и параметры визуального формирования. Менять только подписанные

Для стационарной яркости опорный источник — кадр 2795. Относительное положение
в реальной записи меняет среднюю яркость и контраст по зависимостям,
оценённым на первых пяти временных фрагментах: коэффициенты логарифмического
спада на исходный кадр −2,992083e−5 и −2,770318e−5 соответственно.
Это эффективная модель наблюдаемых картинок, а не восстановленная модель
фотоблекания или нейронной активности. Восемь вариантов сцены используют
разные яркости и экспрессии; биологическая временная непрерывность не заявляется.

Оптика NAOMi: `NA=0.6`, `objNA=0.8`, `lambda=0.92` мкм, `n=1.35`,
`psf_sz=[20 20 50]` мкм, модель распространения исходная.
`vol_depth=30` мкм и эти параметры оптики здесь являются допущениями модели,
а не параметрами, восстановленными из Zenodo. Крупные сосуды, пирамидальные
дендритные деревья, движение и форма всей рыбы в локальном пресете отключены.
Фон представляет неразрешённую флуоресценцию приближённо.

## Как выполнялась настройка и проверка

Эталон: `01_ZebrafishMul_GCaMP6s_485x400x9800_highSNR.tif`.
Фактический массив одного кадра — 400 строк × 485 столбцов, signed int16.
Через HTTP Range прочитаны 128 кадров: восемь окон по 16 соседних кадров,
равномерно распределённых по записи. Размер, тип, расположение strips и IFD
проверялись для каждой прочитанной страницы. Весь файл 3,86 GB не скачивался;
его полный MD5 не проверен. SHA-256 локальной выборки сохранён.

Четыре участка 64×64 без контура рыбы и крупных чёрных артефактов:

| Участок | Строка y | Столбец x |
|---|---:|---:|
| A | 112 | 300 |
| B | 142 | 380 |
| C | 234 | 350 |
| D | 105 | 230 |

Координаты от нуля. Область задаётся `frame[y:y+64, x:x+64]`.
Первые пять временных окон использованы для настройки; последние три —
для проверки в тех же четырёх местах. Новые синтетические геометрии 22,23
не участвовали в численном подборе камерных параметров на геометрии 21.
Это проверка по времени внутри одной записи, не проверка на новых рыбах
и не независимый тест на ранее невиденных областях мозга. Предварительные
варианты подбора сохранены отдельно; итоговые значения относятся к v5.

Морфология оценивается одним и тем же простым детектором на средних 16 кадров:
Gaussian 0,65 px минус фон Gaussian 4 px, максимумы не ближе 3 px,
watershed, площадь 5–100 px, исключение объектов у края.
Число 49 или 42 — число объектов, найденных этим детектором, а не точное
число всех нейронов. В итоговых синтетических масках 92–122 клетки, включая
слабые вклады, которые автоматический детектор не разделяет или не находит.

Проверенные медианы на поздних фрагментах:

| Характеристика | Реальные | Синтетические |
|---|---:|---:|
| Найденные объекты на 64×64 | 49 | 42 |
| Эквивалентный диаметр объекта | 4,46 мкм | 4,75 мкм |
| Ближайший сосед | 5,13 мкм | 5,43 мкм |
| Средняя яркость | 22278 ADU | 22369 ADU |
| Стандартное отклонение яркости | 2568 ADU | 2784 ADU |
| Робастный шум по разности кадров | 1981 ADU | 2231 ADU |
| Доля насыщенных пикселей | 0,317% | 0,244% |

Инженерные допуски: диаметр ±20%, число/расстояние/яркость/шум ±25%,
насыщение ±5 процентных пунктов. Яркость и квантили сравниваются после
вычитания электронного смещения, чтобы большое смещение не скрывало различия.
Все 11 проверок в этом наборе пройдены. Это выбранные допуски для первого
приближения, не критерий доказанного биологического реализма.

## Откуда берутся маски

Для каждой клетки рассчитывается собственный оптический вклад NAOMi.
Маска — область не ниже 50% её максимального вклада с заполнением внутренних
дыр; пиковый вклад должен быть не ниже 2000 ADU, площадь 5–60 px.
Так широкие размытые и очень слабые вклады не превращаются в огромные метки.
В instance TIFF перекрытие получает ID более сильного вклада. В NPZ
сохраняются все допустимые пересекающиеся области. Это заданная политика
оптической разметки, не экспертная разметка реального датасета.

Нативные маленькие ядра центрируются внутри тела клетки. Для плотной ткани
устраняются редкие пересечения 3D-вокселей разных клеток, поскольку штатный
MEX NAOMi записывает значения вокселей вместо суммирования. Исходная папка
NAOMi не изменена: адаптация находится в этой папке.

`sparse_scanner.py` ускоряет вычисление тех же линейных свёрток, пропуская
нулевые воксели. Для каждой новой геометрии обязательно сверяет пять
изображений с исходным `scan_volume` в Octave: все клетки, пустой кадр,
две отдельные клетки и случайная смесь. В трёх итоговых сценах наибольшее
относительное расхождение менее 1,2×10⁻⁶. Это проверка вычислений оптики,
а не доказательство сходства с реальной рыбой.

## Как повторить проверку

В PowerShell, из папки проекта:

```powershell
.\naomi_zenodo_stage1\START_STAGE1.cmd --verify 'C:\Users\User\Documents\ChatGPT\Кемп Рыбы\naomi_zenodo_stage1\generated\zenodo_stage1_final'
```

Для нового набора укажи его папку вместо `zenodo_stage1_final`.
Проверка обновит `verification.json`, картинки сравнения и независимый
отчёт чтения TIFF. Ожидаемый результат: `export_integrity_passed=true`,
`similarity_checks_passed=true`; код завершения 0. Код 2 означает, что
картинки сохранены, но хотя бы один допуск сходства не пройден.

Для честного обучения и проверки дели синтетические данные по `anatomy_seed`,
а не случайно по картинкам. Восемь вариантов одного объёма имеют общую
геометрию. Для полноценного обучающего набора нужно больше разных seed.

## Повторное измерение и воспроизводимость

```powershell
.\.venv-naomi\Scripts\python.exe .\naomi_zenodo_stage1\fetch_reference.py
.\.venv-naomi\Scripts\python.exe .\naomi_zenodo_stage1\measure_reference.py
.\naomi_zenodo_stage1\START_STAGE1.cmd --recalibrate
```

Последняя команда заново подберёт камерные параметры по реальной выборке
и создаст новый набор. Сохранённый результат содержит собственную копию
параметров в `manifest.json`.

Среда: GNU Octave 11.3.0, Python 3.12; пакеты перечислены в `requirements.txt`.
Локальная Python-среда — `..\.venv-naomi` относительно этой папки.
Для её восстановления на этом же компьютере:

```powershell
& 'C:\Users\User\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe' -m venv --system-site-packages .venv-naomi
.\.venv-naomi\Scripts\python.exe -m pip install -r .\naomi_zenodo_stage1\requirements.txt
```

Здесь предполагается существующая рабочая установка NAOMi для Octave
`C:\Users\User\NAOMi_octave`. Новый сценарий не заменяет порт Octave.

## Источники и границы результата

- Данные: https://zenodo.org/records/6293696
- Паспорт масштаба/частоты: https://cabooster.github.io/DeepCAD-RT/Datasets/
- Статья DeepCAD-RT, включая Tg(HuC:GCaMP6s): https://doi.org/10.1038/s41587-022-01450-8
- Исходная модель NAOMi: https://doi.org/10.1016/j.jneumeth.2021.109173
- Исходники NAOMi: https://bitbucket.org/adamshch/naomi_sim/

Подтверждено выполнение генерации, согласование масок, целостность файлов
и приближённое совпадение перечисленных характеристик локальных вырезок.
Не подтверждены: идентичность реальных и синтетических изображений,
истинная 3D-анатомия этой рыбы, качество обучения сегментации на этой
синтетике и перенос на другие рыбы/микроскопы. В Zenodo нет экспертных масок,
поэтому точность масок относительно настоящих клеток здесь не измерена.
